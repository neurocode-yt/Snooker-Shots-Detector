# CapCut 9.7 compatibility and local handoff check

The Open in CapCut action rejected 9.7.5.4135 because installation discovery
only allowed the 9.5 and 9.6 release families. Extend that allowlist to 9.7,
retain the neutral 9.5 draft schema, and continue rejecting other release
families. Generated platform metadata uses the discovered installed version.

Regression coverage checks 9.7.0 and 9.7.5 discovery, separate retained shots,
source media references, matching root and timeline drafts, and discovery of a
9.7 update despite a cached 9.6 installation. Versions 9.8, 9.70 and 10 remain
rejected.

longer available after exiting CapCut, and the existing installation resolved

beta update. The 9.7 checks above cover discovery and draft generation only.
